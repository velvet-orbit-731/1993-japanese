# フォントについて

`KHDotKagurazaka12.woff2` は「KHドット神楽坂12」（KH Dot kagurazaka 12, Version 1.00.20150527）です。

- 作者：平木敬太郎（Keitarou Hiraki）/ Font Silo（X68000 版の原作）
- TrueType 化：自家製フォント工房（Homemade Font Factory, http://jikasei.me/）
- ライセンス：SIL Open Font License 1.1（全文は同じフォルダの `OFL.txt`）

配布されている TrueType 版（`KH-Dot-Kagurazaka-12.ttf`）を、Web で読み込みやすいよう WOFF2 形式に変換しただけのもので、字形・収録文字・フォント名などは変更していません。
