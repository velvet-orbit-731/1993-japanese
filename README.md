# 1993（日本語版）

1993年秋、モスクワ。最高会議となって、ホワイトハウスを守り抜け。

ピョートル・ロセフ（Пётр Лосев、[@peterloss](https://x.com/peterloss)）によるブラウザゲーム「[1993](https://ptrls.github.io/1993/)」の日本語版です。1993年のロシア憲法危機を題材にしたターン制のピクセルゲームで、パソコンでもスマートフォン（横向き）でも、ブラウザだけで遊べます。

## 遊び方

- GitHub Pages で公開する場合：`https://velvet-orbit-731.github.io/1993-japanese/`（リポジトリの設定で Pages を有効にする必要があります）
- 手元で動かす場合は、このフォルダで簡単な Web サーバーを起動してブラウザで開きます。

  ```bash
  python3 -m http.server 8000
  ```

  起動後、`http://localhost:8000/` を開いてください。

## 日本語版について

- **言語**：起動時は日本語です。タイトル画面右上の言語ボタンから、ロシア語（原文）・英語・中国語・韓国語へ切り替えられます。URL の末尾に `?lang=ru`（ロシア語）や `?lang=ja`（日本語）を付けて切り替えることもできます。
- **書体**：既定の書体は「KHドット神楽坂12」（後述）です。タイトル画面の「フォント」ボタンから、ゴシック（Noto Sans JP）や明朝（Noto Serif JP）にも切り替えられます（この2つは Google Fonts から読み込みます）。
- **セーブデータ**：言語ごとに分かれて保存されます（日本語版のセーブデータは、ロシア語版などとは共有されません）。

### ファイル構成

| ファイル | 内容 |
|---|---|
| `js/data.ja.js` `js/game.ja.js` `js/interior.ja.js` `js/ach.ja.js` | 日本語の翻訳ファイル。原作のロシア語版（`js/data.js` など）と行単位で1対1に対応 |
| `css/ja.css` | 日本語表示のときだけ使う書体と文字サイズの調整 |
| `fonts/` | KHドット神楽坂12（WOFF2）とそのライセンス |

### 原作からの主な変更点

- 本文、画面表示、メタ情報（説明文など）の日本語化
- 日本語向けの表示調整：日付（「1993年9月21日」）、数値の区切り（「1,000」）、人名の中黒（「・」）、句読点、新聞見出しの区切り方など
- ゲーム内判定の書き換え：原作はロシア語の文字列を照合して判定（効果音の選択、包囲中に使える行動、買収の発生、夜の報告の並び順など）を行っているため、その照合処理を日本語の訳文に合わせて書き換え（ロシア語版と同じ結果になることを確認済み）
- 文字サイズの調整：12px 未満だと漢字がつぶれてしまうため、日本語表示では 12px 未満の文字を 12px に引き上げ
- 言語の選択肢に「日本語」を追加（各言語版のファイルにも反映）
- 原作者のアクセス解析（GoatCounter）への送信処理を削除（実績・統計画面の「全プレイヤー」の数字は、原作の公開カウンターから読み取って表示）
